# 📝 To-Do List Application

A simple, interactive to-do list app built with HTML, CSS, and JavaScript. Your tasks are automatically saved to your browser's local storage, so they persist even after you close the page!

## Features ✨

- ✅ Add new tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Delete tasks
- ✅ Local storage (tasks saved automatically)
- ✅ Clean, user-friendly interface
- ✅ Works offline
- ✅ No account needed

## How to Use 🎯

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add Task" or press Enter
4. Click the checkmark to mark a task complete
5. Click the trash icon to delete a task
6. Your tasks are automatically saved!

## Files 📁

- `index.html` - The main HTML structure
- `style.css` - Styling and layout
- `script.js` - JavaScript logic and local storage
